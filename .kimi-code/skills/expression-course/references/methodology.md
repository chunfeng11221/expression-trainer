## 〇、总纲:两张清单与一条底层逻辑

- **清单一:我在表达过程中是否提升了信息的价值**(视频2提出,3–22逐一展开,src-0022):
  1. 我有表达的动机(视频3–7)
  2. 我了解听众的目的(视频8–11)
  3. 我有一套清晰的框架(视频12–17)
  4. 我能一句话总结核心思想(视频18–22)
  5. 彩蛋:杠点与反驳(视频23–26)
- **清单二:内容如何产生吸引力**:好问题(具体/被忽略/有影响/能解决)→ 具象思考 → 具象表达(视频27–29、32–43)【视频43】。
- **底层逻辑**:"表达不只是一种说话方式,它更是一种思考方式"(视频2,src-0022)。语言呈现的是脑子的状态,"口才好"的三标准——有见解、有条理、真诚自信——全部与嘴无关。整个课程练脑不练嘴:动机解决"为什么讲"(并化解紧张),听众目的解决"对谁讲",框架解决"怎么组织",核心句解决"讲到什么程度",杠点/好问题/具象解决"内容凭什么值钱",彩蛋课(视频44)解决"现场怎么稳住"。

## 一、表达动机:我为什么讲(清单第一项,最重要)

- **定义**:我相信什么、我在意什么、我想改变什么(src-0040【视频5】)。表达目的无非三种:"我有个方法教你 / 我有个主张告诉你 / 我有个观点和你不一样"【视频3】。**动机 > 知识 > 技巧**(src-0040)。
- **为什么重要**:
  1. **化解紧张**。紧张是生物性的:一大群视线+逆光无遮蔽=演化危险信号,血液从大脑抽向四肢→大脑空白。痛感消除不了,只能靠"爽感胜过痛感",动机就是那个爽感(内向的人见到外星人也会想讲)。**自信是结果,不是前提**——人是因为做成了一件事才有自信(src-0033【视频3】)。警惕错误动机:"讲好就能红/被录取"只会放大压力(src-0033【视频5】)。
  2. **挖掘素材**(自我访谈五问,见下)。
  3. **吸引听众**:"讲者自己在意,是最大的吸引力;你自己都不在意,听众更不会在意"(src-0040,张宏飞正反两段对比)。有动机的人,不熟练都会成为"特色"(臧鸿飞的磕巴)。案例:奇葩说杨天真胜过李想、王小川,靠的不是口才是动机感("我有话想说")【视频4】。
  4. **对话感**:心里设定一个具体对象("小明"),台上永远在对某一个具体的人说话【视频5】。
- **怎么做:自我访谈五问**(src-0034【视频4】):① 谁对我影响最大,他做过或说过什么?② 什么会让我真的生气/最想吐槽?③ 最想跟唱反调的人争论什么?④ 受过最惨痛的教训是什么?⑤ 什么赋予我说这些的资格?负面情绪(恐惧/愤怒/沮丧)动力最强(src-0005直播答问)。
- **向内找 vs 向外推**(src-0034/0042【视频4/7】):向内=回溯细节沉浸自我情绪,越讲越窄,听众OS"跟我有什么关系";向外=这件事改变了我什么/我想给别人什么建议。引导话术:"这经历给你最大的影响是什么?对你为人处事带来什么改变?你会对同样处境的人说什么?"向外推≠好为人师(也可以是"我想消除外界对抑郁症的误解")。

## 二、听众分析:对谁讲(清单第二项)

- **听众七大目的**(出自 Scott Berkun,src-0043【视频8】):想学习 / 想获得启发 / 想得到乐趣 / 想看到你 / 想遇到同好 / 想看看有什么新鲜事 / 想早点离开。表达的本质是服务、是利他;表达的交集 = 你想说 × 听众想听。"你很难完全搞砸一场演讲"——七样总能提供一两样,最不济准时收尾。
- **用法**:每场合先暗猜排序——新年会=乐趣+同好;TED=启发+看到你+新鲜事;学术报告=学习+早点离开;行业分享会=学习/启发;小众圈子=同好/新鲜事;会议被Q=早点离开;相亲=想见你(src-0003)。
- **关键区分**:想学习→强调"重要性"(把自己拉高);想获得启发→强调"可迁移"(放低姿态,"我的心得也许对你有用")。满足"遇到同好"靠背景相似、态度相似。新鲜事三标签:**稀少、高价、受限**——内容普通没关系,先把标签包袱包上("这话我只在这儿说")。
- **差异大的听众:三种顺应**(src-0044【视频9】):
  1. **权力顺应**——识别真听众(比赛顺评委;校园演讲要让"老师觉得学生有收获"),诀窍"指着秃子夸和尚":绕个圈讲给学生听,让权力者心里领情。"权力的人喜欢被迎合,不喜欢被针对。"
  2. **多数顺应**——顺现场最大比例(奇葩说七成女性→举例永远用女生第一视角)。"多数是被创造的":"任何差异只要层次一拉高就会被化解"("在座的都是做子女的/做事的人")。
  3. **底层顺应**——让最不懂、最有敌意的人也听得懂。难点是"知识的诅咒":知道的人想象不出"不知道"的滋味(打拍子实验:自以为八九成人听得出,实际不到两成)。学洗发精说明书,每句瞄准听者会卡住的点("挤出硬币大小、沾水搓揉、直至起泡")。
- **引导预期**(src-0044【视频9】):内容不能改时说"我知道大家想要什么,但今天你会得到更多"——先给被理解感,再给内容。兜底判断:"听众永远比你更希望这个演讲是成功的。"

## 三、表达框架:怎么组织(清单第三项)

- **框架的定义**(src-0004):"为解决开放性问题而设计的、具有约束性与支撑性的结构"——既是框子(约束思考范围、检验遗漏)也是架子(支撑内容、便于复盘)。
- **取舍**(src-0004/0005):PREP/AIDA/SCQA/黄金圈对中文使用者不直觉、临场用不上;金字塔只适用职场汇报。"我教的一定是我用的",**框架要熟不要多,三套好过三十套**。
- **三套自用框架**(src-0005):
  1. **过去—现在—未来**——即兴谈看法、致辞、感言万能;比例不必1:1:1。曼德拉/林肯/马丁路德金/乔布斯名篇皆此结构(src-0008)。两问法:过去问"为什么"(什么经历造就这个感受),未来问"我希望"(希望听众得到什么、如何行动),一分钟婚礼致辞也能成篇。
  2. **空雨伞(背景→问题→方案)**——来自日本麦肯锡汉字版(笔记另一处记作"空雨散");可换序(雨空伞/伞空雨)、可调比例,没有方案时也可只讲背景或只分析问题。卡在中间时"用简单的元素倒逼剩下的元素"(先想雨和伞,再补空)(src-0007)。
  3. **3C(问题出现→有人觉得→但我觉得)**——源自大前研一战略模型;加"竞争者"做对照,说服力倍增;"有人觉得"是社会共识做铺垫,"但我觉得"必须形成鲜明对比。
- **衔接(路标)**(src-0006):三种路标——"刚才路过/此处位置/前方将要";视觉路标(投影片只打亮当前点);设问是最弹性的路标;**停顿**也是路标(12–15分钟注意力循环,"暂时停止专心")。判断标准:"听众跟上你的难度越高,跟上你的意愿就越低。"
- **职场应用**(src-0009):短指令用金字塔(结论先行+观点分类);复杂汇报用空雨伞调整篇幅主次(强调问题 or 强调方案);方案要把选择权交还老板。认知习惯:思考是网状的,接收是线性的,框架就是把网状信息排成线。

## 四、核心句与减法:讲到什么程度(清单第四项)

- **表达者的职责是筛选信息,不是提供信息**(src-0010)。"知无不言、言无不尽"是偷懒——你只是信息搬运工,没为听众创造价值。信息爆炸时代,注意力最值钱,讲者要为听众的注意力负责。
- **指挥官目标**(美军概念):如果明天的任务只能完成一项,那是什么?对应表达:"如果这个主题我只能讲一句话,那句话是什么?"= **核心句**。例:Gordon Ramsay"厨师的工作是让人觉得饿";吴庚"法律为原则与例外之学问";说服课核心句"没有人喜欢被改变"。
- **找核心靠减法,不靠指定**(src-0011):练习找**次要内容**,三标准——可被剔除、可被合并、排序较低(唱高调的/不用你说我也知道的/做不到的/不合适的,先删)。逐条筛→合并→排序,剩下的就是核心(小学生"自强自信"演示:核心句="遇到困难学会求助")。
- **排序即内容**(src-0012):吉野家"快速美味便宜"顺序不可改,有排序才能做一线决策;"都很重要"等于口号(乐雅乐"美味第一服务第一卫生第一"=白讲)。逼问"第二重要是什么"才能验证"第一"。为什么把X排第一,本身就是一篇演讲。
- **横向论点 vs 纵向论点**(src-0014):横向=同一逻辑链上的延展(本质一个论点,找链条起点终点即可归纳);纵向=不同逻辑链(多个论点,需删减排序)。用场景测试验证核心对不对("如果法制健全、证据确凿,你还反对死刑吗?")。

## 五、杠点与反驳(彩蛋:专业表达者加餐)

- **杠点同时也是卖点**(src-0015):质疑不是坏事,对抗是吸引元素。预测听众会在哪抬杠并主动说破、主动回应,课程就"掰开揉碎"了(示范:"别说你应该,改说我需要"一路回应四个杠点)。不教必杀技——"只有骗子才教必杀技"。
- **主张三要素**(src-0016):议题、结论、理由。"讲话没逻辑"大多是"没主张":误区一**空话**(逃避结论,"见仁见智/具体问题具体分析"万能套话=零信息);误区二**咏叹**(有结论没理由,只会重复结论)。判断标准:"凡有意义的话都有可能错,不可能错的话都没有意义。"
- **反驳三技巧**(src-0016):对"A是好的,因为A造成B"这一基本句型——① A未必造成B(影响不一定发生);② 没有A也有B(影响没那么特别);③ B不重要(换个新视角)。**内容的盲点就是自我的盲点**:你理所当然拿来做理由的东西,就是你的价值取向投射。
- **拆解观点**(src-0017):生活主张不含标准A→B,先拆再驳:延伸背后议题→判断倾向结论→找出A推B→套三路径。
- **深化观点**(src-0018):逆用三路径强化自己——A往往造成B、没有A就没有B、B很重要。步骤:找A→B→预判反驳→给对应层次解释。上台句式:"A往往造成B,没有A难有B,而B很重要。"

## 六、好问题:内容凭什么值钱(清单二)

- **内容价值来自"它是某个问题的答案"**(src-0019):沟通是双向接球,表达带目的性——目的性就是"提出一个问题"。没思考过问题的人觉得答案不值钱(谜底不给谜面)。"你的内容永远是某个问题的答案;当你没有提出问题之前,人家对你所讲的答案不感兴趣。"【视频33】
- **好问题四标准**(src-0019【视频43】):**具体 / 被忽略 / 对听众有影响 / 能被解决**,每项30分,符合任意两项即及格。
- **具象思考三不**(src-0020):不用大词("格局/做自己/料理人之心")、不谈大道理(只谈普遍原则、不谈操作与冲突的就是废话)、不迷恋大问题(大问题只配大道理)。两把好用的手术刀:① "你所谓的那个词,具体指的是什么?"(警惕重复定义);② "不用这个词,你会怎么描述这件事?"(邝达:"失恋"="我没人爱了"="我会孤独终老",自己就能发现不对)。补充习惯:听评价多问一句"你是怎么看出来的呢?"
- **具象表达**(src-0021):言之有物≠大道理,也≠修辞堆砌("天苍苍野茫茫"里什么都没有)。**用行为与场景代替形容与评论**:"老师的课很无聊"→"听着听着想起了过世的外婆";"电影精彩"→"出来爆米花还剩八分满";"在东京失恋了,幸好酒很强劲"。题目太抽象时("还是要相信")自己设定具体问题("信任感从哪来/如何快速取得陌生人的信任")。
- **具体表达收束技术**【视频30/31】:警惕动词型大词("打了他一下"画面不统一,要"甩了一巴掌");给指令补使用条件:"今天18点前给15个一个月内有联系的客户打拜访电话"。具体+夸张=展现态度。越具体越像流水账?不是具体错了是比例错了——找到承载目标情绪的"单一场景"砍掉干扰("为什么我见过那么多次儿童医院门口刚升起的太阳,孩子的爸爸一次都没见过");**打动人的不是情绪的多,是情绪的纯**。

## 七、吸引力机制:让人听进去(好问题大模块展开)

1. **预测机器**【视频32】:大脑预判信息种类与下文,觉得"我好像懂"就跳过去当背景音——这是听众忽略你的机制;预测机器失灵的一刻,是人最容易修正偏见、接受改变的时刻。做法:提反常识问题("人生不幸福的秘诀是什么");平时攒"意外清单"收集反常识素材,小组可共建共享。"发现=见到+传播:哥伦布不是第一个发现新大陆的人,是最后一个。"
2. **对比(没有清单时平地起高楼)**【视频33/36】:性质对比①"A与B有什么差别"(教育vs洗脑、羡慕vs嫉妒),②变招"什么才是真正的什么"(真正的谦虚=不否认事实,但认知到这品质不足以让你高于他人);操作:先接近再剔除,或反向应用(相反词找相同:自卑其实是一种自恋)。规模对比用于数字(东京人口=澳大利亚+新西兰),王牌要前置,"问题一丢→给数据→再丢问题→再出王牌"。
3. **悬疑公式**【视频34】:问题+猜想+落空=悬疑(推理小说的"糊涂虫警官"负责提错误推理)。意外引起注意,好奇维持注意——15分钟内一个意外就够,长演讲必须靠好奇。别用力过猛变否定听众:用"以前我听过一种答案,可我觉得不太对"、借外星人角色、开场声明"我的问题都没有标准答案"。
4. **共鸣三等级与共鸣升级**【视频37】:一级=暴力/性/金钱(生物面),二级=亲情/友情/职场(社会面),三级=吃喝玩乐。共鸣升级=低级主题+一级元素:"读懂孩子"→"如何知道你的孩子在学校有没有被霸凌";"父母该不该欺骗孩子"→"父母该不该告诉孩子家里不富裕"。"不要瞧不起世俗的力量",手段中性;目标是"帮人误入正途"。
5. **角色与挑战**【视频38/39】:让人在乎的第二法:给听众角色+场景+挑战,他就会投入(游戏的本质=创造人与目标的关系)。"角色"指听众扮演谁,不是讲者扮演谁——用第二人称("如果你是这位老师");选"让你觉得有义务当下给出回应"的场景;预设听众想当然的答案并点出瑕疵。好老师提供答案,顶尖老师让同学关心那个问题;不怕听众有反驳,怕的是听众没想法。
6. **干货三新**【视频40】:干货=新事实(手上有药:乔布斯简报厉害的不是技巧是iPhone)、新观念("你眼中的问题,往往都是别人的解决方案";"所有缺点对当事人都有好处,没有好处的缺点留不住";劝人改缺点=拿走他的拐杖)、新技巧(别列缺点的坏处,要列好处,逐项问"能否用别的方式替代")。为什么都要新:老事实老观念能解决,问题早不存在了。
7. **先射箭后画靶**【视频41/42】:医生模式=问题固定找答案;推销员模式=答案固定找问题。表达者更像推销员:先有要分享的内容,再在外面包一个让它显得命中靶心的问题(手上有水就介绍"渴";把"拖延症"调成"有一件该做的事却不想做,好难过,怎么办")。操作:换角色(女儿:"如何让父亲不要老得那么快")、换场景("如何加班后容光焕发见客户")、把问题放大抽象("如何快速清理灶台油渍"→"如何让一个男人愿意下厨房")。困惑"我没有答案"是错觉:数据趋势是新事实,经验感悟是新观念,小妙招是新技巧。

## 八、现场掌控(视频44,彩蛋课)

- 听众反应取决于**心理距离**而非物理距离(完美场地=埃皮达鲁斯剧场,圆形无角落;遇高台+护城河式烂场地宁可跳下舞台)。
- **善意假设 vs 恶意假设**:假设听众都爱我、纠正我是善意("对不起记错了,我常常记错")——"气氛是相互决定的";善意假设是对对方的拯救,也是拯救你。
- **支持听众**:别死盯滑手机的人,把视线留给听得认真的人,不必扫视全场。
- **结尾**:15分钟内不用设计;长演讲别拿问答当结尾;结尾时听众已累、别再给信息量,给情绪性内容——故事与名言/有印象的比喻/回顾与愿景。

## 九、可操作的训练方法

1. **纸面二分练习**(src-0034【视频4】):左边写"我对X的看法",右边用自我访谈五问挖素材,对比两边数量差距。
2. **动机访谈(小组三人:采访者/受访者/旁观者)**(src-0041【视频6】):采访者用五问挖对方动机(五问是可选项,答不出就换);受访者放开情绪;旁观者记录好提问与动机爆发瞬间。误区:追问打断动机、把自己当唱反调的人(要树立"第三方敌人");多分享探讨、别教人做事。
3. **框架即兴练习**(src-0005直播连麦):随机题目(早恋/躺平/身材焦虑)套过去现在未来、空雨伞、3C各讲一遍;卡住时"用简单的元素倒逼剩下的元素"(src-0007)。
4. **找核心练习**(src-0011/0014):拿一堆标准/守则,逐条判"可剔除/可合并",再排序逼出第一;或写"支持/反对+三个理由",标出横向、纵向论点,用场景测试校验核心句。
5. **杠点自检**(src-0016):给自己的主张写"A是好的因为A造成B",再用三技巧逐条反驳;三招都能驳倒=主张不成熟,回炉。深化时逐条给反解释。
6. **意外清单工程**【视频32/35】:个人随时收集,小组共建;采访外行四步骤——发掘动机("普通人对你们这行最大的误解是什么?")→向外推→找相似→硬关联;定期归纳:删冗余→留关键词→筛选→合并同类项。
7. **性质对比练习**【视频36】:先接近再剔除;相反词找相同;入门作业"命令和请求有什么差别";目标是细化思考的颗粒度。
8. **内行看门道**【视频37/43】:听任何演讲先找"他提了个什么问题",用两张清单打分;做讲题四选一投票。
9. **主题改造练习**【视频38】:拿又空又大的旧主题,用共鸣升级或角色与挑战改写,分组互投最佳问题。
10. **先射箭后画靶练习**【视频42】:盘点手上的"答案"(数据/感悟/妙招),分别练换角色、换场景、问题放大三种包装。
11. **具体表达练习**【视频30】:把自己下的指令里的概括动词圈出来,补时间/人群/方式三条件。
12. **脑暴造框架**(src-0007演示):抓一个词逐字母脑暴成法则,先练"逼出内容",再进阶到"从内容提炼框架"。
13. **小组训练节奏**(src-0001):3–5人成组,带着任务听课→按执行手册训练→交作业教练1v1点评;表达需要反馈,小组是拿反馈的最小单位。
