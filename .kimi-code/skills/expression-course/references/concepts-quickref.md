# 表达课核心概念速查(20 个)

> 一页纸速查,细节与出处见 methodology.md(标注 src-XXXX /【视频N】)。

## 总纲

1. **两张清单**——自查卡片。清单一(信息价值):有动机/懂听众/有框架/能一句话总结;清单二(吸引力):好问题→具象思考→具象表达。【视频2/43】
2. **表达=思考方式**——口才好=有见解+有条理+真诚自信,全与嘴无关;练脑不练嘴。【视频2】

## 动机(为什么讲)

3. **动机**——我相信什么、我在意什么、我想改变什么;动机>知识>技巧;化解紧张靠"爽感压过痛感";自信是结果不是前提。【视频3/5】
4. **自我访谈五问**——谁影响我最大/什么让我真生气/想跟唱反调的人争什么/最惨痛教训/什么赋予我资格。负面情绪动力最强。【视频4】
5. **动机向外推**——向内找(沉浸自我)越讲越窄;向外推(改变了你什么/能给听众什么)才有力量;≠好为人师。【视频4/7】

## 听众(对谁讲)

6. **听众七大目的**——学习/启发/乐趣/看到你/同好/新鲜事/早点离开;表达=你想说×听众想听的交集。【视频8】
7. **三种顺应**——权力顺应(指着秃子夸和尚)、多数顺应(拉高层次化解差异,"多数是被创造的")、底层顺应(知识的诅咒:瞄准听者会卡住的点)。【视频9】
8. **引导预期**——"我知道大家想要什么,但今天你会得到更多";听众永远比你更希望演讲成功。【视频9】

## 框架(怎么组织)

9. **框架=框子+架子**——约束思考范围+支撑内容便于复盘;要熟不要多,三套好过三十套。【视频12】
10. **过去—现在—未来**——即兴谈看法/致辞/感言万能;过去问"为什么",未来问"我希望"。【视频12/13】
11. **空雨伞**——背景(空)→问题(雨)→方案(伞);可换序可调比例;汇报复杂问题首选。【视频14】
12. **3C**——问题出现→有人觉得(共识铺垫)→但我觉得(鲜明对比);说服场景首选。【视频15】
13. **路标**——刚才/此处/前方+设问+停顿;"听众跟上你的难度越高,跟上你的意愿就越低"。【视频14,src-0006】

## 核心句(讲到什么程度)

14. **核心句(指挥官目标)**——"这个主题我只能讲一句话,那句话是什么?"【视频18】
15. **减法三标准**——次要内容:可被剔除/可被合并/排序较低;逐条筛→合并→排序,剩下的就是核心。【视频19】
16. **排序即内容**——"都很重要"等于口号;逼问"第二重要是什么"才能验证"第一"。【视频20】

## 杠点(专业加餐)

17. **杠点即卖点**——预测听众在哪抬杠,主动说破主动回应;质疑是吸引元素。【视频23】
18. **反驳三技巧**——对"A是好的,因为A造成B":A未必造成B / 没有A也有B / B不重要;逆用即"深化观点"(往往造成/没有就难/很重要)。【视频24/26】

## 好问题与具象(内容凭什么值钱)

19. **好问题四标准**——具体 / 被忽略 / 对听众有影响 / 能被解决;每项30分,符合两项即及格;内容永远是某个问题的答案。【视频27/43】
20. **具象表达**——三不:不用大词、不谈大道理、不迷恋大问题;两把手术刀:"具体指的是什么?""不用这个词怎么描述?";用行为与场景代替形容与评论("课很无聊"→"听着听着想起了过世的外婆");打动人的不是情绪的多,是情绪的纯。【视频28–31】

## 吸引力机制(进阶)

- **预测机器**:听众觉得"我懂"就走神;反常识问题制造意外,意外清单平时攒。【视频32】
- **悬疑公式**:问题+猜想+落空;意外引起注意,好奇维持注意。【视频34】
- **共鸣升级**:低级主题+一级元素(暴力/性/金钱),"帮人误入正途"。【视频37】
- **角色与挑战**:给听众角色+场景+挑战(第二人称),让人在乎。【视频38/39】
- **干货三新**:新事实/新观念/新技巧;旧的能解决,问题早不存在了。【视频40】
- **先射箭后画靶**:先有答案,再包一个命中的问题(换角色/换场景/放大抽象)。【视频41/42】
- **善意假设**:气氛是相互决定的;结尾别给信息量,给情绪性内容。【视频44】
